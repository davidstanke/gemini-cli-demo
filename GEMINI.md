## DIRECTIONS

**Test-driven development**
ALWAYS use test-driven development. When implementing any functionality...
1. Create a failing test to validate the functionality to be implemented
2. Run the test to confirm that it fails
3. Implement the desired functionality
4. Re-run the test.
   * If it succeeds, exit
   * If it fails, modify the code (NOT THE TEST) and return to step 3.
