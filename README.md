## About FreshFinds

FreshFinds is a gourmet recipe inspiration tool that helps you make the most of your local market specials.

### Features
- **Daily Yield**: Browse curated deals on fresh produce, meats, bakery, and pantry staples.
- **AI-Powered Inspiration**: Select the ingredients you have, and our culinary AI (powered by Gemini 1.5 Flash) crafts 3 unique, gourmet recipes.
- **Visual Plating**: See your creation before you cook it with AI-generated food photography (powered by Gemini 2.0 Flash).
- **Modern Experience**: Smooth animations and a clean, responsive interface designed for the home chef.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
